# 01 · 奖励与回报

## 1. 从 VLA 理解强化学习

以“把胡萝卜放到盘子里”为例：

- 模仿学习：根据专家示范，学习给定输入时应该采取什么动作。
- 强化学习：策略与环境交互，利用奖励反馈调整行为。

| RL 概念 | 机器人任务中的例子 |
| --- | --- |
| 观测 | 相机图像、机器人本体信息等 |
| 策略 | 根据观测、语言指令等输入生成动作的 VLA |
| 动作 | 末端移动、旋转、夹爪开合等控制指令 |
| 奖励 | 环境对一次交互给出的数值反馈 |
| Episode | 从环境重置到终止或截断的一段交互 |
| 轨迹 | 这段交互中的观测或状态、动作、奖励等数据序列 |

相机观测可能遗漏遮挡区域等信息，因此观测 $o_t$ 不一定等于完整状态 $s_t$。实际策略也可能使用历史观测。

## 2. 奖励是单步反馈

本文将执行动作 $a_t$ 后获得的奖励记为 $r_t$：

$$
s_t \xrightarrow{a_t,\;r_t} s_{t+1}
$$

举例采用如下奖励规则：成功完成任务的那一步奖励为 $1$ 并终止，其他步骤奖励为 $0$，失败结束的奖励也为 $0$。

这只是一个用于学习的稀疏奖励设计，实际任务的奖励可以不同。

```text
动作：    靠近 → 抓取 → 放入盘子
奖励：     0      0       1
```

前两步奖励为零，不代表动作无用；它们可能是最终成功的必要条件。

## 3. 回报是从当前开始的累计奖励

对于包含 $T$ 个动作、在 $s_T$ 真正终止的轨迹，从第 $t$ 步开始的折扣回报为：

$$
G_t = \sum_{k=0}^{T-t-1}\gamma^k r_{t+k},
\qquad 0 \leq t < T
$$

展开为：

$$
G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2}
+ \cdots + \gamma^{T-t-1}r_{T-1}
$$

其中 $\gamma$ 是折扣因子。在有限长度轨迹中，通常取 $0 \leq \gamma \leq 1$：

- $\gamma=1$：直接累加从当前开始的所有奖励。
- $0<\gamma<1$：越晚获得的奖励，权重越小。
- $\gamma=0$：只考虑当前一步奖励。

这里累计的是**从当前开始的未来奖励**，不是从任务开始到当前已经获得的奖励。

若讨论无限时域，则写作：

$$
G_t = \sum_{k=0}^{\infty}\gamma^k r_{t+k}
$$

当奖励有界且 $0\leq\gamma<1$ 时，该级数收敛。不能把有限轨迹中 $\gamma=1$ 的用法直接推广到任意无限时域任务。

## 4. 数值例子

完整奖励序列为 `[0, 0, 1]`，取 $\gamma=0.9$：

| 时刻 | 当前奖励 | 从当前开始的回报 |
| --- | --- | --- |
| $t=0$ | $r_0=0$ | $G_0=0+0.9\times0+0.9^2\times1=0.81$ |
| $t=1$ | $r_1=0$ | $G_1=0+0.9\times1=0.9$ |
| $t=2$ | $r_2=1$ | $G_2=1$ |

同一条轨迹中，不同时刻的回报可以不同，因为累计的起点不同。

比较两条轨迹：A 的奖励为 `[0, 0, 1]`，B 的奖励为 `[0, 1]`。

- 当 $\gamma=0.9$ 时，A 的初始回报为 $0.81$，B 为 $0.9$。
- 当 $\gamma=1$ 时，两者的初始回报都是 $1$。

在这个“只有终点成功奖励为正、其他奖励为零”的例子里，折扣让更早成功的轨迹获得更高回报。若奖励设计不同，不能直接套用这一结论。

## 5. 容易混淆的地方

- **奖励不等于回报**：前者描述单步反馈，后者累计后续反馈。
- **回报不等于价值预测**：一次采样轨迹有对应的实际回报；价值函数描述给定条件下回报的期望，下一篇会初步介绍。
- **成功轨迹中不一定每个动作都好**：轨迹可能包含冗余动作。回报有助于让后续结果影响前面的决策，但不等于识别了每一步的因果贡献。
- **日志中的 episode return 不一定带折扣**：不少实现记录整条 episode 的原始奖励之和，读代码时应核对定义。

## 6. 复习题

取 $\gamma=0.9$，计算以下完整轨迹从第一步开始的回报：

1. A：`[0, 0, 1]`
2. B：`[0, 1]`
3. C：`[0, 0, 0]`
