# 05 · 策略如何学习：用优势调整动作概率

前置知识：[动作价值与优势](04-action-value-and-advantage.md)。

上一课知道了：优势为正，说明动作比当前平均水平好；优势为负，说明比当前平均水平差。

这一课回答：**怎样把这个评价变成策略参数的更新，让策略以后更倾向于选择好的动作？**

先读第 1–3 节，理解更新方向；再读损失公式与代码。这里学习基础策略梯度的思路，暂不加入 PPO 的概率比和裁剪。

## 1. 策略输出的概率是什么意思？

继续用机器人抓着胡萝卜、夹爪停在盘子边缘上方的状态 $s$。仍然只考虑两个动作：

- 动作甲：向盘子中心移动一点。
- 动作乙：立即松开夹爪。

为了学习，我们把策略简化为输出两个动作的概率：

```text
输入状态 s → 策略网络 → 动作甲的概率：0.5
                     → 动作乙的概率：0.5
```

随后按照这个分布抽取一个动作执行。概率 `0.5` 表示在这个状态下选择该动作的可能性，不是执行后成功的概率。也不是让机器人执行“一半的甲动作”。

写成符号：

$$
\pi_\theta(a_{\text{甲}}\mid s)=0.5
$$

意思是：参数为 $\theta$ 的策略，在状态 $s$ 下选择动作甲的概率为 `0.5`。$\theta$ 就是策略网络的权重等参数。

本课使用离散动作方便理解。实际 VLA 的动作表示和概率计算需要结合具体模型，不能直接假定都是两个选项。

## 2. 一条样本如何提供更新方向？

假设机器人这次抽到了动作甲。执行后继续采样，算出这次动作的优势估计：

$$
\hat A=+0.3
$$

这条样本给出的更新信号是：**增加在这个状态下选择动作甲的倾向。**

例如，一次更新后，概率可能从：

```text
更新前：甲 0.50，乙 0.50
更新后：甲 0.52，乙 0.48
```

这里的 `0.52` 只是示意，实际变化取决于学习率、模型和整批数据。

如果这次甲动作的优势估计是负数，这条样本推动的方向就相反。

| 所采动作的优势估计 | 这条样本推动的方向 |
| --- | --- |
| 正数 | 提高所采动作在该状态下的概率 |
| 负数 | 降低所采动作在该状态下的概率 |
| 零 | 该样本的这一项策略损失不提供更新信号 |

这说的是单条样本的作用方向。实际网络在多个状态间共享参数，一批数据共同更新，也可能包含其他损失，因此不能保证每个样本对应的动作概率最终都按各自期望变化。

## 3. 更新概率，实际是在更新网络参数

不是保存一句“以后甲的概率改成 0.52”，而是调整策略网络的参数，让它再次接收这个状态时输出不同的概率。

```text
采集状态、动作、奖励等数据
        ↓
计算所采动作的优势估计
        ↓
重新计算：当前策略给这个已采动作多少概率？
        ↓
用动作概率与优势构造策略损失
        ↓
反向传播，更新策略参数 θ
```

“重新计算”这一步使用的是数据里已经执行过的动作，不是为了计算这条样本的损失再抽一个新动作。

## 4. 什么损失能实现这个方向？

先看单条样本，一种基础策略梯度损失写成：

$$
L_{\text{policy}}(\theta)=-\hat A\log\pi_\theta(a\mid s)
$$

优化器的目标是让这个损失变小。先把公式缩短，设所采动作的概率为 $p$：

$$
L=-\hat A\log p
$$

这里的 $\log$ 是自然对数。理解更新方向只需要知道：**$p$ 越大，$\log p$ 也越大。**

| 所采动作的概率 $p$ | $\log p$，近似值 |
| --- | --- |
| 0.2 | -1.609 |
| 0.5 | -0.693 |
| 0.8 | -0.223 |

### 优势为正时

设 $\hat A=+0.3$：

| 概率 $p$ | 损失 $-0.3\log p$，近似值 |
| --- | --- |
| 0.5 | 0.208 |
| 0.8 | 0.067 |

提高概率，损失变小。所以最小化这个损失，会推动所采动作的概率增大。

### 优势为负时

设 $\hat A=-0.3$，此时 $L=+0.3\log p$：

| 概率 $p$ | 损失 $+0.3\log p$，近似值 |
| --- | --- |
| 0.5 | -0.208 |
| 0.2 | -0.483 |

降低概率，损失变得更小：`-0.483` 小于 `-0.208`。因此最小化损失，会推动所采动作的概率减小。

损失可以为负数；它是用于构造更新方向的量，不是成功率或误差次数。

### 为什么用 log？

前面的表格解释了“这个损失能推动概率朝正确方向变化”，但还没有解释为什么选择 log。要理解原因，先区分两个步骤：

1. 如果知道所有动作的平均回报，应该怎样更新策略？
2. 实际只采到部分动作，怎样用这些样本估计同一个更新方向？

下面只考虑固定状态下的一次决策，执行动作得到奖励后就真正终止。这样不必同时考虑后续策略变化。

**第一步：先看真正想提高的目标。**

假设策略只有两个动作：

| 动作 | 选择概率 | 执行后的平均回报 |
| --- | --- | --- |
| 甲，记作 $a_1$ | $p$ | $0.8$ |
| 乙，记作 $a_2$ | $1-p$ | $0.2$ |

策略的平均回报为：

$$
J(p)=p\times0.8+(1-p)\times0.2=0.2+0.6p
$$

所以，提高 $p$ 会提高平均回报。比如 $p$ 增加 $0.01$，$J$ 就增加 $0.006$。

这里暂时直接把 $p$ 当作可调参数，并且只讨论 $0<p<1$ 的情况：

$$
\frac{dJ}{dp}=0.6
$$

这个导数可以理解为“$p$ 每变化一小份，$J$ 对应变化的比例”。**我们希望从采样中估计出来的，正是这个 $0.6$ 的更新信号。**

注意，这个目标里还没有 log。

**第二步：采样频率已经带上了动作概率。**

假设当前 $p=0.75$。采样 100 次，通常会有大约 75 次选甲、25 次选乙。每次都从同一个起始状态开始，采样期间策略保持不变。

甲出现得更多，因此如果把每条样本的更新信号直接取平均，甲的信号自然会被计入更多次。

为了看出问题，先试一种做法：每次采到动作后，使用“该动作的平均回报 × 该动作概率对 $p$ 的导数”作为信号。本例中：

$$
\frac{d\,p}{dp}=+1,\qquad
\frac{d(1-p)}{dp}=-1
$$

因此，采到甲时的信号是 $0.8\times(+1)=+0.8$，采到乙时的信号是 $0.2\times(-1)=-0.2$。

按照采样频率，信号的期望为：

$$
0.75\times(+0.8)+0.25\times(-0.2)=0.55
$$

得到的是 $0.55$，不是目标梯度 $0.6$。原因是：本来需要把两个动作的“回报 × 概率导数”直接相加，采样平均却额外按动作的出现概率加了权。

这里先假设知道两个动作的平均回报，只为了看清采样带来的权重。实际中可以用采到的回报代替平均回报，不过会增加随机性。

**第三步：每次抽中后除以该动作的概率，就能抵消采样频率。**

采到甲时，信号改为 $+0.8/0.75$；采到乙时，信号改为 $-0.2/0.25$。这些信号按采样概率取平均：

$$
\begin{aligned}
0.75\times\frac{+0.8}{0.75}+0.25\times\frac{-0.2}{0.25}
&=+0.8-0.2\\
&=0.6
\end{aligned}
$$

这样就与目标梯度一致了。有限次采样不一定恰好得到 $0.6$；这里计算的是样本信号的期望。

关键操作就是：**采到一个动作后，把“回报 × 该动作概率的导数”除以该动作被选中的概率。**

**第四步：log 的导数恰好实现这个除法。**

如果用 $\theta$ 表示策略网络参数，数学上有如下关系。这里 $\nabla_\theta$ 表示对参数 $\theta$ 求梯度，不是对概率本身求导：

$$
\nabla_\theta\log\pi_\theta(a\mid s)
=\frac{\nabla_\theta\pi_\theta(a\mid s)}{\pi_\theta(a\mid s)}
$$

其中 $\pi_\theta(a\mid s)$ 是所采动作的概率。用文字读就是：“log 概率的梯度，等于概率的梯度除以概率。”

所以，每条样本所需的信号可以写成下面两种等价形式。用 $G$ 表示这次实际采到的回报：

$$
G\frac{\nabla_\theta\pi_\theta(a\mid s)}{\pi_\theta(a\mid s)}
=G\nabla_\theta\log\pi_\theta(a\mid s)
$$

这就是 log 出现的原因：它的导数恰好提供了所需的“除以动作概率”，使按当前策略采样得到的更新信号，在平均意义上对应目标梯度。

**第五步：接回本课的策略损失。**

我们想增加平均回报，而优化器通常通过减小损失更新参数，因此加上负号：

$$
L_{\text{policy}}(\theta)=-G\log\pi_\theta(a\mid s)
$$

也就是“负的实际回报 × 所采动作的 log 概率”。

进一步，可以从回报中减去一个只依赖当前状态的基准值。本例中，如果基准值为 $b$，它对期望梯度的额外贡献为：

$$
-b\left[\frac{d\,p}{dp}+\frac{d(1-p)}{dp}\right]
=-b[+1+(-1)]=0
$$

因此，在求策略梯度时把基准值当作固定量，可以保持期望更新方向不变。用状态价值预测作为基准，就得到本课的形式：

$$
\hat A=G-V_\phi(s),\qquad
L_{\text{policy}}(\theta)=-\hat A\log\pi_\theta(a\mid s)
$$

这是通过样本损失的梯度来估计平均回报的梯度，并不表示“平均回报等于平均 log 概率乘回报”。求这条样本的策略梯度时，已采到的动作和优势估计都作为固定数据。

可以先检查自己是否理解这条链：**想提高平均回报 → 只能通过采样估计梯度 → 采样频率带有动作概率 → 每条信号除以该概率 → log 的导数恰好提供这个除法。**

以上用一次决策解释 log 的来源。完整多步任务还要处理各时刻的数据、回报与采样权重，本节不展开完整策略梯度定理。

## 5. 优势在更新时扮演什么角色？

可以把优势看成这条样本对策略更新的一个带正负号的权重：

- 正负号决定鼓励还是抑制所采动作。
- 在其他条件相同时，绝对值越大，该样本对梯度的权重越大。

计算这项策略损失时，优势估计通常当作固定的学习信号，**不通过它反向传播到价值网络**。价值网络会用自己的价值损失训练。

例如，同一条样本中，实际回报为 `1`、价值预测为 `0.6`：

```text
价值网络的学习：预测 0.6，目标 1 → 这条样本推动预测上升
策略网络的学习：优势估计 1 - 0.6 = +0.4 → 鼓励这次采到的动作
```

两者学习的内容不同：价值网络学习预测回报，策略网络学习选择动作。下一课会用 Actor-Critic 的名字把它们串起来。

## 6. 运行一个最小更新例子

为了不用安装深度学习框架，下面只用 Python 标准库。把固定状态下的策略简化为一个可训练参数 $z$：

$$
p_{\text{甲}}=\frac{1}{1+e^{-z}},\qquad p_{\text{乙}}=1-p_{\text{甲}}
$$

这叫 sigmoid 映射。当前只要知道：$z=0$ 时，甲的概率为 `0.5`；$z$ 增大，甲的概率增大。

假设采到的动作是甲。对损失 $L=-\hat A\log p_{\text{甲}}$ 求导后，有：

$$
\frac{\partial L}{\partial z}=-\hat A(1-p_{\text{甲}})
$$

梯度下降就是“参数减去学习率乘以梯度”。不熟悉求导也可以先运行代码，观察正负优势带来的变化：

```python
import math

def probability_of_a(z):
    return 1.0 / (1.0 + math.exp(-z))

def update_for_sampled_a(z, advantage, learning_rate=0.1):
    # 只处理本例中“采到动作甲”的一条样本。
    p_a = probability_of_a(z)
    gradient = -advantage * (1.0 - p_a)
    return z - learning_rate * gradient

for advantage in [0.3, -0.3, 0.0]:
    # 三个独立实验，每次都从相同的参数开始。
    z_before = 0.0
    z_after = update_for_sampled_a(z_before, advantage)
    print(
        f"优势 {advantage:+.1f}："
        f"甲的概率 {probability_of_a(z_before):.4f}"
        f" → {probability_of_a(z_after):.4f}"
    )

# 优势 +0.3：甲的概率 0.5000 → 0.5037
# 优势 -0.3：甲的概率 0.5000 → 0.4963
# 优势 +0.0：甲的概率 0.5000 → 0.5000
```

这段代码真实更新了一个策略参数，但只演示单状态、单条样本的更新方向，没有环境采样，也不是完整 RL 训练。

## 7. 为什么不能拿同一条成功样本一直更新？

样本优势可能受随机结果和价值预测误差影响。一次成功，不代表这个动作在所有情况下都好。

而且，这批数据是在采集时的策略下得到的。策略改变后，后续行为和对应价值可能改变，旧优势不再准确描述新策略。

因此，不能仅凭某条样本的损失持续下降，就认定任务表现持续改善。这个基础公式也不是允许对任意旧数据无限重复更新的规则。

后续会学习 PPO 如何利用新旧策略的概率比和裁剪目标控制更新。本课先记住：需要不断用环境反馈检验更新后的策略。

## 8. 复习题

以下题目只讨论单条样本的基础策略损失，不考虑整批样本或其他损失的影响。

1. 策略给动作甲的概率为 `0.7`，是否意味着执行甲之后任务成功率是 70%？
2. 这次采到动作甲，优势估计为 `+0.4`。策略损失推动甲的概率增加还是减少？
3. 这次采到动作乙，实际回报为 `0.2`，价值预测为 `0.6`。用回报减预测计算优势估计。虽然回报为正，这条样本会鼓励乙吗？
4. 某条样本的优势估计为零，它的这项策略损失还会推动参数更新吗？
5. 价值网络预测 `0.6`，实际回报 `1`。价值网络和策略网络分别在学习什么？

<details>
<summary>查看答案与解释</summary>

1. 不是。`0.7` 表示策略在当前状态下选择甲的概率，描述动作选择，不是任务成功概率。
2. 增加。正优势对应 $L=-0.4\log p$，提高所采动作的概率 $p$，会使这项损失减小。
3. 优势估计为 $0.2-0.6=-0.4$。不会鼓励乙；这条样本推动乙的概率降低，因为本次结果低于预测的平均水平。
4. 不会。这项损失及其对策略参数的梯度为零；其他样本或损失仍可能推动参数更新。
5. 价值网络根据目标 `1` 修正回报预测；策略网络利用正优势估计 `+0.4`，增加所采动作的倾向。两者不是在拟合同一个输出。
