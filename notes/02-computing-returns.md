# 02 · 训练时如何计算回报

前置知识：[奖励与回报](01-reward-and-return.md)。

核心思路：**先采样获得奖励，再计算回报；尚未采到的未来部分，可以用价值函数估计。**

## 1. 先采样，再更新

以采样后再更新的训练流程为例：

```text
当前策略与环境交互
        ↓
保存观测、动作、奖励、终止/截断标记等数据
        ↓
计算回报或优势等训练量
        ↓
构造损失，更新参数
```

策略选择动作时，不需要事先知道这次执行最终会成功还是失败。完整轨迹的实际回报可以在交互结束后计算。

## 2. 完整轨迹：从后往前递推

假设轨迹包含 $T$ 个动作，并且在 $s_T$ 真正终止。

终止之后没有后续奖励，设：

$$
G_T=0
$$

根据回报的定义，可以得到递推式：

$$
G_t=r_t+\gamma G_{t+1},
\qquad t=T-1,T-2,\ldots,0
$$

这个式子把当前回报拆成两部分：当前奖励，加上下一步回报的折扣值。注意，**下一步回报已经包含更后面的所有奖励**。

奖励为 `[0, 0, 1]`、$\gamma=0.9$ 时：

$$
\begin{aligned}
G_3 &= 0,\\
G_2 &= 1+0.9\times0=1,\\
G_1 &= 0+0.9\times1=0.9,\\
G_0 &= 0+0.9\times0.9=0.81.
\end{aligned}
$$

使用采样到的完整后续奖励计算回报，称为 Monte Carlo（蒙特卡洛）回报。

## 3. 代码实现

下面的函数处理**单条连续轨迹片段**，片段内部不能包含 episode 重置：

```python
def discounted_returns(rewards, gamma, bootstrap_value=0.0):
    """计算单条轨迹片段中每一步的折扣累计目标。

    真正终止：bootstrap_value = 0。
    采样截止但任务尚未终止：可传入片段末尾状态的价值预测。
    """
    returns = [0.0] * len(rewards)
    G = float(bootstrap_value)

    for t in reversed(range(len(rewards))):
        G = rewards[t] + gamma * G
        returns[t] = G

    return returns


rewards = [0, 0, 1]
returns = discounted_returns(rewards, gamma=0.9)
print([round(value, 4) for value in returns])
# [0.81, 0.9, 1.0]
```

`bootstrap_value=0` 适用于这里的完整终止轨迹。若片段尚未终止，随意设零会丢掉剩余回报。

## 4. 没采到任务结束：用价值函数补上剩余部分

假设只采集了从第 $t$ 步开始的 $n$ 次转移，最后到达 $s_{t+n}$，任务尚未终止。

此时已经知道：

$$
r_t,r_{t+1},\ldots,r_{t+n-1}
$$

但不知道从 $s_{t+n}$ 开始还会获得多少奖励。

先在完整状态可用于建模的设定下，定义策略 $\pi$ 的状态价值函数：

$$
V^\pi(s)=\mathbb{E}_{\pi}\left[G_t\mid s_t=s\right]
$$

含义是：从状态 $s$ 开始，继续按照策略 $\pi$ 行动，平均能获得多少回报。期望同时涉及策略和环境带来的随机性。有限时域任务若价值依赖剩余时间，应将时间纳入状态，或显式写成带时间下标的价值函数。

用神经网络 $V_\phi(s)$ 近似这个期望，可以构造 $n$ 步自举目标：

$$
\hat G_t^{(n)}
=\sum_{k=0}^{n-1}\gamma^k r_{t+k}
+\gamma^n V_\phi(s_{t+n})
$$

- 第一部分：实际采到的 $n$ 个奖励。
- 第二部分：估计尚未采到的剩余回报，并折扣到当前时刻。
- 帽子符号表示这是估计目标，不是完整后续轨迹的实际回报。

这种使用价值预测补上未来部分的方法叫 **bootstrapping（自举）**。

实际 VLA 通常接收观测而非完整状态。价值网络可能使用观测、历史信息，或训练时可用的额外状态；不能默认单张图像就是完整的马尔可夫状态。

### 数值例子

采到两个奖励 `[0, 0]` 后暂停采样，取 $\gamma=0.9$，假设末尾状态的价值预测为 $0.8$：

$$
\hat G_0^{(2)}
=0+0.9\times0+0.9^2\times0.8
=0.648
$$

代码调用：

```python
returns = discounted_returns(
    [0, 0], gamma=0.9, bootstrap_value=0.8
)
print([round(value, 4) for value in returns])
# [0.648, 0.72]
```

这里的 $0.8$ 是为了演示而假设的网络预测，不是额外收到的环境奖励。

## 5. 真正终止与截断

| 情况 | 是否考虑剩余价值 |
| --- | --- |
| 任务按其定义真正终止，例如成功或不可恢复的失败 | 不考虑，终止后的价值为零 |
| 只因 rollout 长度达到上限而停止采样，任务尚未结束 | 通常需要自举：用末尾状态的价值预测补足剩余回报 |
| 环境因外部时间限制而截断，但目标任务理论上仍可继续 | 通常需要自举：用末尾状态的价值预测补足剩余回报 |
| 有限时域任务本身规定到时就结束 | 按真正终止处理；价值建模需要考虑剩余时间 |

这里的“使用末尾状态的价值预测”和“自举”指的是同一种处理方式：将已采到奖励的折扣和，加上折扣后的末尾状态价值预测，作为回报估计。

Rollout 是策略与环境交互并收集数据的过程。达到 rollout 长度上限，表示这一批数据已经收够，通常不必重置环境，可以从当前状态继续采集；外部时间限制导致截断，则表示环境结束了本次运行，通常需要重置。两者停止采集的原因不同，但这里补足剩余回报的方法相同。

因此，不能只看“超时”两个字就决定是否自举，需要确认任务定义和环境接口。

实现时还要注意：

- 自动重置环境时，自举使用的是**重置前的末尾观测**，不能误用下一个 episode 的初始观测。
- 轨迹缓存可能包含多个 episode，不能把下一个 episode 的奖励累计到上一个 episode。
- 价值自举是否保留、递推是否跨越 episode 边界，是不同的问题。后续学习 GAE 时再具体处理对应的掩码。

## 6. 与 PPO 的关系

上述方法解释了回报及自举的基本计算。实际 PPO 实现还经常使用 GAE，结合单步奖励和价值预测估计优势，并据此构造价值训练目标。

当前先记住：

- 完整轨迹可以直接计算 Monte Carlo 回报。
- 未完成的轨迹片段可以使用价值预测补足未来部分。
- PPO 的策略更新通常使用优势估计，不是把回报直接当作监督动作标签。

GAE、价值损失和策略损失的具体公式，在对应知识点中展开。
