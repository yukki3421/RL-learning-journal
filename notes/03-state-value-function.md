# 03 · 状态价值函数：预测未来能拿到多少回报

前置知识：[训练时如何计算回报](02-computing-returns.md)。

本课只解决一个问题：**上一课用于自举的“末尾状态价值预测”，到底是什么，又是怎么得到的？**

建议先读第 1–4 节，理解价值函数的含义；再读第 5–7 节，理解预测如何学习、如何用于自举。最后完成练习。本课暂不展开 Q 函数、优势函数和 PPO 损失。

## 1. 从上一课留下的问题开始

上一课采到两个奖励 `[0, 0]`，任务尚未结束。我们假设末尾状态的价值预测是 `0.8`，取 $\gamma=0.9$：

$$
\hat G_0=0+0.9\times0+0.9^2\times0.8=0.648
$$

这里的 `0.8` 表示：

> 从采样停止时的状态继续执行当前策略，预计还能获得多少折扣回报。

它不是环境额外发放的奖励，也不是已经观测到的结果，而是一个预测。

为什么能做这种预测？因为训练过程中会收集很多“在什么状态，后来拿到了多少回报”的数据，可以用这些数据学习状态与后续回报之间的关系。

## 2. “函数”在这里是什么意思？

先把函数理解为一个**输入到输出的对应关系**。

例如，策略和价值函数接收状态信息，但回答不同的问题：

```text
策略：      当前状态 → 如何选择动作
价值函数：  当前状态 → 按当前策略继续执行，预计能拿到多少回报
```

以“把胡萝卜放进盘子”为例，状态可能包含胡萝卜位置、夹爪位置、是否抓稳等信息。价值函数根据这些信息输出一个数。

这个数的含义由任务奖励、折扣因子和当前策略共同决定。不能仅凭“离盘子更近”，就断定价值一定更高：机器人也可能快要把胡萝卜掉下去了。

这里先用完整状态 $s$ 讲概念。实际 VLA 接收的相机图像等是观测 $o$，可能不包含完整状态；价值网络也可能使用观测、历史信息，或训练时额外可用的状态。

## 3. 一次实际回报，与平均回报

假设可以把环境反复恢复到同一个起始状态，并且保持策略不变。

奖励规则仍是：成功那一步奖励为 1 并终止，其余奖励为 0。取 $\gamma=0.9$，得到四次运行：

| 运行 | 完整奖励序列 | 从起始状态开始的实际回报 |
| --- | --- | --- |
| 第一次 | `[0, 0, 1]` | $0.81$ |
| 第二次 | `[0, 0, 0]`，失败并真正终止 | $0$ |
| 第三次 | `[0, 0, 1]` | $0.81$ |
| 第四次 | `[0, 0, 0]`，失败并真正终止 | $0$ |

同一个状态为什么会有不同结果？策略可能随机选择动作，环境也可能存在随机性。

这四次回报的平均值是：

$$
\frac{0.81+0+0.81+0}{4}=0.405
$$

因此，可以用 `0.405` 作为这个状态价值的一个样本估计。

**一次回报描述某一次的结果；状态价值描述按当前策略继续行动时，回报的期望。** 四次采样的平均值只是估计，不保证等于真正的期望。

## 4. 现在再看价值函数的公式

$$
V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s]
$$

逐项理解：

| 符号 | 含义 |
| --- | --- |
| $s_t=s$ | 当前处在状态 $s$ |
| $G_t$ | 从当前开始的折扣回报 |
| $\pi$ | 后续使用的策略 |
| $\mathbb E$ | 对可能出现的结果取期望，可以先理解为大量重复运行后的平均水平 |
| $V^\pi(s)$ | 状态 $s$ 在策略 $\pi$ 下的价值 |

其中，上标 $\pi$ 是在说明“使用哪个策略”，不是乘方。

“当前策略”不能省略理解：同一个状态，熟练策略和不熟练策略的后续表现可能不同，所以状态价值也可能不同。策略改变后，对应的价值也可能需要重新学习。

如果任务本身规定了截止时间，那么剩余时间也可能影响价值；这时需要把时间纳入状态，或使用带时间下标的价值函数。

### 价值是不是成功概率？

一般不是。只有在“成功时奖励 1 并终止，其余奖励全为 0，并且 $\gamma=1$”等条件下，每次回报才恰好是成功记 1、失败记 0，因此期望回报等于成功概率。

上面的例子中，样本成功率是 $2/4=0.5$，但样本平均折扣回报是 $0.405$。因为 $\gamma=0.9$，成功奖励被折扣了。

## 5. 价值函数与价值网络是什么关系？

需要区分两个符号：

| 符号 | 含义 |
| --- | --- |
| $V^\pi(s)$ | 我们想知道的期望回报 |
| $V_\phi(s)$ | 用参数为 $\phi$ 的模型做出的预测 |

在神经网络实现中，$\phi$ 就是网络的权重等参数。**价值网络是用来近似价值函数的模型。** 对简单问题，也可以用表格记录每个状态的价值，并不一定需要神经网络。

例如：

```text
当前状态 s
    ↓
价值网络，参数为 φ
    ↓
输出 0.6，表示预测从这里开始的回报为 0.6
```

网络输出 `0.6`，不代表真实价值一定是 `0.6`。预测会有误差，需要根据采样数据进行训练。

## 6. 价值网络怎么学？先用完整轨迹理解

先考虑最容易理解的方法：收集真正终止的完整轨迹，算出实际回报，用它作为训练目标。

```text
用当前策略采集完整轨迹
        ↓
根据奖励，从后往前计算每一步的回报 G_t
        ↓
组成训练数据：(状态 s_t，实际回报 G_t)
        ↓
训练价值网络，让预测 V_φ(s_t) 接近回报 G_t
```

一种基本损失是均方误差：

$$
L_V(\phi)=\frac{1}{N}\sum_{i=1}^{N}\left(V_\phi(s_i)-G_i\right)^2
$$

这里 $i$ 是训练样本编号，$N$ 是样本数量。这个公式的意思是：计算每条样本的“预测减目标”，平方后取平均，让这个误差尽量小。

同一状态有时成功、有时失败，网络应该学哪一个？**在样本具有代表性、数据足够且模型能拟合的条件下，均方误差会推动它学习平均回报。** 它不需要把每一次随机结果都预测准确。

下面只针对第 3 节的同一个状态，用一个数模拟预测，观察不同预测值的误差：

```python
sample_returns = [0.81, 0.0, 0.81, 0.0]
mean_return = sum(sample_returns) / len(sample_returns)

def mse(prediction, targets):
    return sum((prediction - target) ** 2 for target in targets) / len(targets)

print(f"样本平均回报：{mean_return:.3f}")
for prediction in [0.0, mean_return, 0.6, 0.81]:
    print(f"预测 {prediction:.3f}，均方误差 {mse(prediction, sample_returns):.6f}")
```

运行后可以看到，在这些候选值中，预测样本平均值 `0.405` 的误差最小。这段代码用于理解训练目标，没有实现神经网络或参数更新。实际训练也不要求把同一个状态重复采集很多次；网络会利用不同状态的数据学习可泛化的规律。

## 7. 接回上一课：用学到的预测自举

有了价值网络，采样只进行一部分时，就可以这样计算：

```text
s_0 → s_1 → s_2，收够这一批数据，任务尚未结束
  r_0=0  r_1=0
```

假设网络对末尾状态的预测为：

$$
V_\phi(s_2)=0.8
$$

那么，取 $\gamma=0.9$：

$$
\hat G_0=r_0+\gamma r_1+\gamma^2V_\phi(s_2)=0.648
$$

这里的 `0.8` 已经是在预测**从 $s_2$ 开始的全部后续折扣回报**，并非只预测下一步奖励。外面的 $\gamma^2$ 则把这个预测折扣到 $s_0$ 对应的时刻。

第 6 节使用完整轨迹解释了价值网络如何学习；实际训练也可以使用带自举的目标训练价值网络。预测不必事先完全准确，但预测误差会影响自举目标，后续再学习如何权衡。

## 8. 复习题

1. 同一状态出发的一次实际回报是 `1`，能否因此断定这个状态的价值就是 `1`？为什么？
2. 固定策略，从同一状态出发获得四次完整回报 `[1, 0, 1, 0]`。样本平均回报是多少？如果价值网络预测为 `0.8`，按这批数据，预测应向哪个方向调整？
3. $V^\pi(s)$ 与 $V_\phi(s)$ 分别表示什么？网络预测一定准确吗？
4. 采到两个奖励 `[0, 0]`，任务尚未结束，末尾状态价值预测为 `0.5`，$\gamma=0.9$。从片段起点开始的自举回报估计是多少？
5. 第 4 题中，如果第二步已经让任务真正终止，还应该使用 `0.5` 吗？

<details>
<summary>查看答案</summary>

1. 不能。一次回报是一个样本，价值是给定状态、按固定策略继续执行时回报的期望。
2. 平均值是 `0.5`；预测应向下、朝 `0.5` 调整。这只是基于这批样本的目标，不保证真实价值恰好是 `0.5`。
3. 前者是策略 $\pi$ 下的期望回报，后者是参数为 $\phi$ 的模型预测。预测可能有误差。
4. $0+0.9\times0+0.9^2\times0.5=0.405$。
5. 不应该。真正终止后的剩余价值为零，这个片段起点的回报为零。
